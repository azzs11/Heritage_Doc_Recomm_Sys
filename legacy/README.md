# Legacy evaluation artefacts

These files were produced by the original HeritageRec evaluation (up to and
including the ICICACS 2026 conference submission). They are kept here so that
the conference version remains traceable, but they are **superseded** and must
not be used as evidence for any new claim.

The current evaluation is being rebuilt from scratch under the upgrade plan
(see UPGRADE_PLAN.md). Numbers that appear in any new paper must come from
scripts that regenerate them from a tagged commit, not from files in this
folder.

---

## Files and why each is superseded

### data/balanced/balanced_documents.json
449 documents including 80 synthetic/augmented copies generated by `nlpaug`
and `deep-translator`. Synthetic copies inflate precision artificially. The
live corpus is `data/classified/classified_documents.json` (303 real documents,
no augmentation).

### data/evaluation/ground_truth.json
Ground truth built by marking every document in the same K-Means cluster as
the query document as relevant. Cluster membership is an output of the pipeline
being evaluated, so relevance labels are circular.

### data/evaluation/ground_truth_improved.json
### data/evaluation/ground_truth_stats.json
### data/evaluation/ground_truth_stats_improved.json
"Improved" version uses a 5-signal weighted formula
(embedding 0.30 + metadata 0.25 + entity overlap 0.15 + SimRank 0.20 +
cluster 0.10). SimRank (signal 4) and cluster membership (signal 5) are
both outputs of the recommender being evaluated. Labels are still circular.

### data/evaluation/ground_truth_v2.0_dev.json
### data/evaluation/ground_truth_v2.0_test.json
Dev and test splits that each contain exactly one query (seed_005:
"Ancient Indian cave paintings and rock art") with 50 documents labelled
relevant by the circular multi-signal formula above.

### data/evaluation/annotations_demo_annotator_1.json
### data/evaluation/annotations_demo_annotator_2.json
Simulated annotation files. Annotator IDs are "demo_annotator_1" and
"demo_annotator_2"; rationale strings follow the pattern
"Matches X/4 expected characteristics", which is a scoring formula run by
the annotation generator, not human judgement. No real annotators were used.

### data/evaluation/annotator_agreement_report_v2.0.json
Inter-annotator agreement report for the simulated annotations above.
Overall Cohen's kappa: 0.149. Reported as kappa 0.63 in the conference
paper; that figure is the "overall_score" from
data/entity_importance/computed_scores.json (5 entities only), not
inter-annotator agreement.

### data/evaluation/recommender_results.json
System output for a single query (seed_005). The evaluation was run on
this one query.

### data/evaluation/annotation_interface_v2.json
Annotation interface template generated for distribution to human annotators.
Distribution never happened; the demo annotation files above were generated
programmatically instead.

### data/evaluation/bias_detection_report_v2.0.json
Bias report derived from the simulated annotations. No evidentiary value.

### data/entity_importance/computed_scores.json
Entity importance scores for 5 entities only (Taj Mahal, Red Fort, Shah Jahan,
Mughal Empire, Unknown Temple). Appears to be a demo run. The live entity
importance data is in knowledge_graph/horn_weights.json (2,409 entities).

### evaluation/evaluation_report.md
### evaluation/comprehensive_evaluation_report.json
### evaluation/ltr_comparison.json
### evaluation/fairness_report.json
### evaluation/explanation_quality_study.json
All produced by the single-query evaluation run described above. The report
header states "Queries evaluated: 1". LTR models were trained on 54 samples
from 1 query type.

### results/evaluation_results.json
### results/method_comparison.json
Method comparison (SimRank-Only P@5 = 0.768, NDCG@10 = 0.700) computed on
the one-query circular ground truth. P@5 figures in the conference paper
come from this file.

### frontend/public/data/evaluation_results.json
Copy of the stale evaluation results served to the Next.js dashboard.
